# 碎步

给容易对长任务失去兴趣的人用的个人专注小工具。把一个大目标拆成很短的步骤，用可配置的短时专注做完一步，再用完成度、连续天数和兴趣温度看见自己没有放弃。

数据只存在这台浏览器的 `localStorage`（键名 `suibu.v1`）。没有账号，没有后端。

## 本地运行

在仓库根目录启动静态服务器：

```bash
python3 -m http.server 8765
```

浏览器打开 <http://localhost:8765>。

也可以：

```bash
npx serve .
```

第一次成功打开后，Service Worker 会缓存页面、样式和脚本。之后即使断网，刷新仍可使用已缓存的文件。计时和进度都在本地，不需要网络。

`file://` 直接打开 `index.html` 时，页面本身通常也能用，但 Service Worker 不会注册。建议用上面的静态服务器。

## 第一次打开

如果这台浏览器里还没有 `suibu.v1`，会放入三个示例大目标（写论文、练吉他、准备小分享），每一步都是几分钟能停下来的小事。

在「设置」里可以清空并恢复这些示例。用户自己把目标都删掉之后，不会自动再塞回示例。

## 可以做什么

- 今日：查看当前一步、步骤列表，开始某一小步；也可以快速再加一步
- 新建或编辑大目标：排序、删除、单独设置 5/10/15/25 分钟，或跟随默认时长
- 专注：倒计时、暂停、完成、跳过。还剩超过 2 分钟时，可以点「只再做 2 分钟」，把剩下的承诺缩短，已经走过的时间仍算数。时间到了可以选择收工或再续 5 分钟
- 提前收工也算完成。刚坐下就点完成时，会记成「这一步落地」，而不是失败
- 今日里如果另有更短的未完成步骤，当前一步旁边会有「改做更短的」
- 已完成的步骤默认收起，避免列表变长。可以点开再看
- 休息：时长可选不休息 / 3 / 5 / 10 分钟。休息结束不会自动开始下一步
- 进度：总完成度、连续天数、兴趣温度、今天落地的小步、近 14 天完成步数、上一次专注、每个目标的进度

跳过不计入完成度，也不计入连续天数。完成才会。

## 文件

- `index.html` 页面入口
- `css/app.css` 样式
- `js/logic.js` 纯逻辑：统计、连续天数、兴趣温度、计时剩余、示例数据
- `js/store.js` `localStorage` 读写
- `js/app.js` 界面
- `sw.js` 离线缓存
- `tests/logic.test.js` 逻辑测试

## 测试

```bash
node --test tests/logic.test.js
```

## 手动确认

1. 打开页面，应看到三个示例大目标。
2. 新建一个大目标并加上步骤，刷新后仍然在。
3. 开始一步专注，点「这一步完成」。
4. 打开「进度」，完成度、今天的柱子和「上一次专注」应已更新。
